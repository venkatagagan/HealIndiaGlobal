# Agent (facilitator) walkthrough - screen coverage

Two videos (split because the full tour is ~10 min): `agent-walkthrough-part1.mp4` (5:44) and `agent-walkthrough-part2.mp4` (4:41).
Story: agent Chinedu Okafor (Lagos MedConnect Travel) registers **Zainab Bello** (Nigeria), screens her right-knee osteoarthritis, requests quotes from two matched hospitals,
compares and accepts one, books the treatment, pays the deposit (test gateway), and tours the rest of the portal. Recording script: `docs/demo/scripts/record-agent.mjs`.
Subtitles: `agent-walkthrough-part1.srt` / `agent-walkthrough-part2.srt` (+ .vtt). Narration: `narration.json` (both parts).

## Not shown (and why)

- Mobile layout - skipped as instructed.
- KYC document upload / "Submit for review" - the demo agent is already approved and verified; the KYC card is shown in its approved state.
- Adding a payout account - the demo agent already has a verified primary account; the page and the "Add another account" option are shown.
- Destructive dialogs (cancel case, cancel booking, decline quote, re-attest consent, edit patient) - not opened to keep demo data intact; the delete-account dialog is opened and cancelled.
- Bank-transfer payment / Razorpay checkout - only the test gateway works in the local stack; both options are visible on the pay page.
- Patient detail Screenings/Cases tabs - not opened separately (the same data is shown on the Screenings and Cases pages).
- Agent registration (/register on the website door) - out of scope for a signed-in agent tour.
- Commission items are real seeded data from an earlier completed treatment (Grace Okafor); the new booking only earns commission once treatment completes.
